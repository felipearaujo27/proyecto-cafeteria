☕ Proyecto Cafetería - Sistema de Pedidos en Python
Aplicación desarrollada en Python para la gestión de catálogos de productos, control de pedidos y generación automática de facturas en consola. Este proyecto forma parte de mi formación en desarrollo de software.

🚀 Tecnologías utilizadas
Python (Lógica de programación, estructuras de datos, funciones y POO).

Visual Studio Code (Editor de código).

Git y GitHub (Control de versiones).

📋 Funcionalidades principales

*Catálogo de productos: Visualización interactiva de los artículos disponibles en la cafetería.

*Gestión de pedidos: Selección de productos y cantidades de forma dinámica.

*Generación de facturas: Cálculo automático de totales, impuestos y emisión de un resumen detallado de la compra en la consola.
